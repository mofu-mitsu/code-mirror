# CODE MIRROR

**コード比較ラボ** — 変更前と変更後のコードを比較して、「どこが変わったのか」「何行追加・削除されたのか」を確認するための小さな開発者向けツールです。

変更後のJavaScriptは、その場で構文チェックもできます。

## できること

- 変更前 / 変更後の2ペインエディタ
- 行単位の差分比較
- 追加された行の表示
- 削除された行の表示
- 追加と削除がセットになった「変更ブロック」の集計
- 変更後コードの構文チェック（JavaScript / TypeScript / Python / HTML / CSS）
- 構文エラーの推定行・列の表示
- HTMLの開始タグ・閉じタグ対応チェック
- 統合差分 / 左右比較の表示切り替え
- 最初の差分位置への自動スクロール
- サンプルコードの読み込み
- ブラウザ内だけで処理（入力コードをサーバーへ送信しない）

## 使い方

1. 「変更前」に元のコードを貼り付ける
2. 「変更後」に修正後のコードを貼り付ける
3. **「比較して原因候補を探す」**を押す
4. 差分マップで追加・削除・変更箇所を確認する
5. 「統合表示 / 左右比較」を切り替えて変更前・変更後を見比べる
6. 構文チェックで変更後コードのエラー位置を確認する

「サンプル」を押すと、すぐに比較を試せます。

## 差分の仕組み

コードを行ごとに分割し、**LCS（最長共通部分列）**を使って変更前と変更後で共通している行を特定します。

そのうえで、

- `＋` = 追加
- `−` = 削除
- 空白 = 変更されていない行

として差分を表示します。

連続した追加・削除をひとまとまりの「変更ブロック」として扱うため、例えば1行を別の1行に置き換えた場合は、**追加1行・削除1行・変更1箇所**として確認できます。

## 構文チェック

- **JavaScript / TypeScript**: Babel Parserをブラウザから遅延読み込みして構文解析します。TypeScriptは型注釈・interface・型などを含む構文を解析できます。
- **Python**: Lezer Python parserをブラウザから遅延読み込みして構文解析します。読み込みできない場合は基本構文の補助チェックへフォールバックします。
- **HTML**: 独自のタグ対応チェックに加えて `DOMParser` でも確認します。
- **CSS**: ブラウザの `CSSStyleSheet.replaceSync()` を使って構文を確認します。

構文チェックはコードを実行するものではありません。比較・解析処理はブラウザ側で行います。外部パーサーは必要になった言語を選択したときだけ読み込みます。

## 対応言語

現在のエラーチェック対象は **JavaScript / TypeScript / Python / HTML / CSS** です。

- JavaScript: Babel Parserによる構文解析＋補助チェック
- TypeScript: Babel ParserのTypeScript / JSX構文解析
- Python: Lezer Python parserによる構文解析＋フォールバック
- HTML: タグ対応チェック＋DOMParserによる解析
- CSS: CSSStyleSheetによる解析＋構造チェック

差分比較そのものは、言語を問わずテキストとして利用できます。

## バグ原因候補

「比較して原因候補を探す」では、構文エラーの位置と今回追加された変更行を照合します。これは確定診断ではなく、「まずここを見ろ」という調査優先順位です。

## 多言語UI

初回アクセス時はブラウザ言語とタイムゾーンを参照して日本語 / 英語を選びます。日本語ブラウザ、またはAsia/Tokyoなら日本語、それ以外は英語です。ヘッダーから手動切り替えもできます。

## 差分表示モード

通常の統合差分に加えて、**左右比較モード**を搭載しています。左に変更前（削除は赤）、右に変更後（追加は緑）を並べるため、長いコードでも変更箇所を見比べやすくなります。

比較を実行すると、最初の差分位置までエディタと差分パネルを自動スクロールします。

## エラー位置について

構文エラーの行・列はパーサーが返す位置を優先します。パーサーが位置を返せない場合だけ補助的な構造チェックを使います。したがって「バグの実行時原因」を断定するものではなく、調査を始める位置を示すための情報です。
