CODE MIRROR / HELP

CODE MIRRORの使い方

コードの変更点と、変更後に発生した構文エラーをまとめて調査するためのツールです。

01　コードを入れる

「変更前」に元のコード、「変更後」に修正したコードを貼り付けます。

02　言語を選ぶ

「チェック対象」から構文チェックしたい言語を選択します。差分比較だけなら言語は問いません。

03　比較する

差分を表示し、変更ブロックを確認します。最初の変更箇所へ自動スクロールします。

04　エラーを調べる

構文エラーがあれば行・列と候補を表示。「次のエラー」「次の変更」で順番に移動できます。

入力したコードは基本的にブラウザ内で処理されます。共有機能はコードをURLに埋め込むため、共有URLの取り扱いには注意してください。
